# Solar Desktop

Solar, the coding agent from [Solar Harness](https://github.com/TerminalDev-1/SolarHarness), in a desktop window: a live timeline of what Solar is doing, and every file change as a green and red diff you can review.

## Run it

You need Node.js 20 or newer, npm, and the Codex desktop app or Codex CLI (signed in).

```powershell
npm install
npm start
```

Open a project folder, then ask Solar for something. `npm run demo` shows the interface with a scripted Solar and no Codex calls.
