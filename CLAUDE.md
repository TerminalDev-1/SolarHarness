# CLAUDE.md

`npm install` builds `dist/` via `prepare`, so installs straight from GitHub work; `npm run check` type-checks; `npm test` builds then runs `tests/*.test.mjs` (they import `dist/`; filter with `--test-name-pattern`). Tests mock `harness.provider.run`/`resume`, so they don't prove live Codex or browser behavior. `test/` is runtime output: never commit it.

TS ESM (`.js` imports), Ink UI, Codex CLI backend (`codex-provider.ts`). `harness.ts` `converse()` loops one main session through structured host turns (`host-turn.ts`). New host tool: update `tool-registry.ts`, `HOST_TOOLS`, and the manifest filter in `harness.ts`. `workspace_command` `run`/`start` (and Codex's own shell) run hidden, and windows they open inherit that (Windows Terminal launched from them stays invisible); `terminal` opens a visible window via `Start-Process -WindowStyle Normal` (Terminal.app / `x-terminal-emulator` elsewhere) and reset never closes it. Workspace is the launch dir; `/new` empties it only if it's named `test`. `SOLAR.md` (`instructions.ts`): home, parent-of-`test`, workspace. `/plan`, `/ultraplan`, `/ultrareview` use read-only `planner` sessions. Codex `file_change` items become `File: Created/Edited x (lines a-b)` events (`file-changes.ts`) shown as a step list, interleaved with `Note:` narration (non-JSON agent messages; the prompt asks Solar to narrate); reasoning summaries (`model_reasoning_summary="detailed"`) become `Thinking:` labels. Solar replies render via `markdown.ts`. Startup effort = `--reasoning` or `settings.ts` `defaultEffort` (`$SOLAR_HOME/settings.json`, fallback max); `/effort` is session-only. Vision: `images.ts` finds image paths in a message; so do + images (`attachments.ts`: Tab picker, Ctrl+V/Alt+V clipboard; no mouse capture, which would break scrolling), passed as `converse`'s `attachedImages` and previewed with `thumbnails.ts` (sharp, half-block cells). All of these and browser screenshots attach via `--image=` (the `=` stops the multi-value flag eating the prompt). Prompts reach Codex on stdin as `-` (`spawnCodex`), never as an argument: long prompts overflow Windows' 32K command line (spawn ENAMETOOLONG). `/model` picker lists `models.ts` (Codex model slugs); `setModel` keeps the main session (Codex resumes across models) and updates new sub-agents. `/ultra` (`converseUltra`) runs one turn at max + Fast and restores settings. Ultra commands show max effort and spin the rainbow faster.

Rules:
- Update this file for agent/tool contract changes, README for user-facing ones; after UI changes rerun `npm run docs:screenshots` so README images stay accurate. After verifying a requested change, commit only its files and push.
- Versioning: never bump the version for ordinary changes. The build commit (`version.ts`, `scripts/build-info.mjs`) identifies each change as `v1.1 build <commit>`; keep it shown in the header and `--version`. Change `package.json`'s version only when the user asks for a new release.
- Every version bump (only when the user asks, never per commit) must also update the README: the "what's new" note at the top, version and build examples, and anything the release changed. Then commit the bump, rerun `npm run docs:screenshots` so every screenshot shows the new version, and commit the screenshots.
- Never weaken tests. Credit Solar only for recorded successful tool calls.
- Delegate only on explicit request or `/delegate`; max 8 agents, two levels, sub-delegates pinned Light. Auto-approve never bypasses `/new` confirmation. Wording heuristics never gate tool availability.
- UI: header and finished messages go in Ink `<Static>`; keep the live area shorter than the window, or Ink clears the terminal each frame and breaks scrolling. ASCII sun, one solid-color label span, no emoji-capable glyphs or per-char ANSI (image thumbnails are the one exception: static colored `▀` cells), short activity labels, rotating full-spectrum rainbow input frame by default in all themes (ultra spins it faster); no cards, status panels, `Ready` badge, or silver palette.
